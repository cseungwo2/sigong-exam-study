# 스마트빌딩시공학 중간고사 CBT

강의자료(조성형, 1~8주차) 필기에서 강조한 부분(★·암기·나옴·밑줄·동그라미)만으로 만든 4지선다 74문제 + 주관식 8문제.
받은 기출 요약 PPT 문제는 넣지 않았다. 문제마다 정답·해설·근거 쪽수가 나오고, 오답노트가 자동으로 쌓인다(브라우저 저장).

- 모의고사: 객관식 40(주차 비율대로) + 주관식 5 = 45문제, 100점 환산
- 주차별: 1~2주차 콘크리트 재료 / 3~4주차 가설·토공사 / 5주차 기초공사 / 6~8주차 철근콘크리트 / 주관식

## 로컬 실행

```bash
python -m http.server 8000
# http://localhost:8000
```

## 구조

`도시계획기사 학습앱(dosi-exam-study)`과 같은 구조. `data/questions.js` 문제은행, `js/app.js` 화면, `js/mock.js` 모의고사 뽑기(`node --test tests/*.test.mjs`).
